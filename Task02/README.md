# PRODIGY_ST_02

## Task-02: Compatibility Testing for a Basic Web Page

### Objective

To perform compatibility testing on an E-commerce Demo Website across multiple browsers and devices, identify functionality issues, and document the findings.

---

## Browsers Tested

* Google Chrome
* Mozilla Firefox
* Microsoft Edge

---

## Devices Tested

* Desktop (1920 × 1080)
* Tablet (768 × 1024)
* Mobile (375 × 667)

---

## Test Cases Covered

* Website Launch Verification
* Navigation Menu Testing
* Homepage Layout Verification
* Product Category Testing
* Product Image Verification
* Responsive Design Testing
* Search Functionality Testing
* Clothing & Accessories Category Testing

---

## Defects Identified

### BUG_001 – Search Button Not Working

* Search functionality failed to return results.

### BUG_002 – Clothing & Accessories Category Returns 404 Error

* Clicking the category redirects users to a 404 Page Not Found page.

---

## Deliverables

* Compatibility_Test_Report.md
* Screenshots Folder
* Browser Compatibility Results
* Device Compatibility Results
* Defect Reports
* Findings and Recommendations

---

## Tools Used

* Google Chrome
* Mozilla Firefox
* Microsoft Edge
* Windows 11
* Visual Studio Code

---

## Conclusion

Compatibility testing was successfully performed across multiple browsers and devices. The website maintained responsiveness and compatibility; however, two functional defects were identified and documented for future resolution.
